1. افتح https://github.com/ وأنشئ حساباً مجانياً أو سجّل الدخول.
2. اضغط New repository.
3. سمّ المستودع: husseinirannews
4. اختر Public ثم Create repository.
5. ارفع ملف index.html من Add file ثم Upload files، وبعدها Commit changes.
6. افتح Settings ثم Pages.
7. ضمن Build and deployment اختر Deploy from a branch.
8. اختر branch: main والمجلد: /(root)، ثم Save.
9. انتظر اكتمال النشر. سيكون الرابط غالباً:
